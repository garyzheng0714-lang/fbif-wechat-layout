# ADR: 素材引用统一使用 `{{asset#id}}`

日期：2026-06-03

## 决策

规则后台和默认配置中新写入的素材引用一律使用 `{{asset#id}}`。

渲染期继续兼容旧的 `{{asset:usage}}`，只作为历史数据降级读取；选图器、服务端默认、前端离线默认和规则数据迁移均不再主动产出 usage token。

## 原因

- `id` 是稳定素材实体引用，替换图片只改素材 URL，所有引用方自动生效。
- `usage` 是用途分类，不是唯一实体引用；同一 usage 下可能有多张图，容易造成“改了不应用”或选错图。
- 这与素材库/DAM 的成熟做法一致：内容持有不可变素材标识，展示名称、用途、标签和 URL 可编辑。

## 约束

- 素材 ID 创建后在后台只读。
- 删除素材前必须检查引用；存在引用时阻断删除。
- 旧 `{{asset:usage}}` 解析兼容不能删除，除非完成历史规则批量迁移并有测试保护。
