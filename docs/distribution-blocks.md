# 外发通用版正文块

> 由 `api/distribution_rules_doc_test.go` 按现在的代码生成，别手改：改了规则跑 `cd api && SPEC_UPDATE=1 go test -run TestDistributionRulesDoc .`。

排版工具把第三方平台都一样的规则（`api/distribution_rules.go`）落进正文块，经 `POST /v1/platforms/<平台>/drafts` 的 `blocks` 交给分发服务（FBIF-多平台分发工具）。每种块在各平台写成什么标签、平台的标题与封面限制只在分发服务的 `docs/platforms/<平台>.md`；排版工具经 `GET /v1/platforms` 取限制，推送前检查用。原文的块是什么见 [article-blocks.md](article-blocks.md)。

## 块

| 块 | 字段 | 说明 |
| --- | --- | --- |
| `h` | text, level | 小标题：level 2 是标题1（原文 level 0–2），3 是标题2（原文 level 3、4） |
| `txt` | runs | 段落；整段加粗的段落是一个加粗片段。不认得的块、前面没有图的图注也按段落给 |
| `bq` | runs | 引用 |
| `li` | runs | 列表项，连着的几项是一个列表 |
| `img` | src | 图片，src 是已转存的公网地址；没转存的图连同图注不给 |
| `cap` | text | 紧跟在 img 后面的图注，图下面的说明与「图片来源」已并成一条 |
| `table` | rows | 表格，每格 runs，表头格带 header |
| `video` | src, poster | 视频；视频地址没转存时改给 img，src 是视频封面 |

`runs` 里每个片段只有 `type`（固定 `txt`）、`text`、可选 `bold`。没有链接、空行、图片尺寸这些字段，分发服务收到多一个字段就 400。文末总有一段转载声明（正文里已有「转载请联系授权」就不补）。封面不在块里，单独给 `cover_url`。

## 各平台一样的规则

每条配一篇最小的稿子真跑一遍。外发块一行一块，加粗写成 `**字**`。

### 署名挪到文末声明

开头不放署名。开头几块和正文最后的署名行（作者、编辑、编译稿的英文来源、中文编辑……）按原文顺序写进文末「本文为FBIF食品饮料创新原创，作者：X，编辑：Y，转载请联系授权。」

原文：

- 段落：作者：Sage
- 段落：编辑：Bobo
- 段落：正文第一段。

外发块：

```
txt 正文第一段。
txt 本文为FBIF食品饮料创新原创，作者：Sage，编辑：Bobo，转载请联系授权。
```

### 小标题编号

两个以上的标题1 编「一、二、」（结语也编）；原文已经编了号、以及参考来源，不动。

原文：

- 小标题（level 2）：市场变了
- 段落：正文。
- 小标题（level 2）：新品牌冒头
- 段落：正文。

外发块：

```
h2 一、市场变了
txt 正文。
h2 二、新品牌冒头
txt 正文。
txt 本文为FBIF食品饮料创新原创，转载请联系授权。
```

### 图注与图片来源并成一条

图下面的说明和「图片来源」用「；」并成一条（前一句以！？收尾就不加），不截短；首图留在原位带图注。

原文：

- 图片
- 图注：▲ 苦味气泡水
- 图注：图片来源：品牌官网
- 段落：正文。

外发块：

```
img https://img.example.com/photo.jpg
cap ▲ 苦味气泡水；图片来源：品牌官网
txt 正文。
txt 本文为FBIF食品饮料创新原创，转载请联系授权。
```

### 正文不带链接

链接只留字，裸网址删掉。

原文：

- 段落：详见品牌官网（链接 https://example.com/news），或访问https://example.com/news。

外发块：

```
txt 详见品牌官网，或访问。
txt 本文为FBIF食品饮料创新原创，转载请联系授权。
```

### 整段加粗并成一个加粗片段

所有字都加粗的段落给一个加粗片段，平台按加粗段写；段内局部加粗照原样分片段。

原文：

- 段落：**整段****加粗**
- 段落：段落里**局部加粗**的字。

外发块：

```
txt **整段加粗**
txt 段落里**局部加粗**的字。
txt 本文为FBIF食品饮料创新原创，转载请联系授权。
```

### 去掉作者名片

作者名片（参考来源上方或之后的无图注图；没有参考来源时，文末无图注的宽条图）不放：平台会提示「图片含二维码」并限制推荐。

原文：

- 段落：正文最后一段。
- 图片：作者名片（宽条图，无图注）

外发块：

```
txt 正文最后一段。
txt 本文为FBIF食品饮料创新原创，转载请联系授权。
```

## 标准答案

编辑在各平台手发的稿是标准答案，样稿考卷分两半：排版工具 `api/testdata/distribution-golden/` 存 FoodTalks 正文和这边写出的块（`<编号>.blocks.json`，`TestDistributionBlocksGolden`），分发服务 `test/golden/` 拿同一份块按各平台写法写出来、和编辑稿逐块比（`test/golden.test.mjs`）。
