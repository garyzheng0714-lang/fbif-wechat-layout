## ADDED Requirements

### Requirement: 章节小标题按第一性视觉信号识别，不依赖单篇样例巧合属性

系统 MUST 仅依据微信排版的稳定视觉信号来判定章节小标题（`K="h"`）：
**字号相对正文放大（≥18px）**、**居中**、**短文本（≤40 字）**，
并 MUST 排除图片来源行、参考来源头、灰色或小字图注。

系统 MUST NOT 把「文本是否含冒号」或「文本 run 是否全部落在 `<b>`/`<strong>` 祖先下」
作为识别章节标题的**必要**条件。加粗与冒号 MAY 作为额外的充分命中路径，但它们缺失时，
只要满足上述第一性信号，仍 MUST 判为标题。

#### Scenario: 居中大字标题——无 `<b>`、无冒号（真实病样 02）

- **WHEN** 一个居中的 `<p>`，内层 span 字号 20px、颜色 rgba(0,0,0,0.9)、无 `<b>` 包裹、
  文本「四大品牌差异化竞争策略拆解」（无冒号），出现在编号图之后
- **THEN** 该块判为 `K="h"`（章节小标题），而非 `K="txt"`（正文）

#### Scenario: 居中大字标题——有 `<b>`（真实病样 01）

- **WHEN** 同篇文章另一个居中 20px 标题「新鲜零食四强品牌共性特征」外层多包了一层 `<b>`
- **THEN** 该块同样判为 `K="h"`——与 02 结果一致，不因多/少一个 `<b>` 而分叉

#### Scenario: 居中大字标题——带冒号（历史样例）

- **WHEN** 居中 20px 文本「文化美好：求真，行善，分享美」，无 `<b>`
- **THEN** 判为 `K="h"`（冒号存在与否都不改变结论）

### Requirement: 非标题的居中大字块仍被正确排除

第一性信号放宽后，系统 MUST 继续把「看起来像标题但语义不是」的居中大字块排除在 `K="h"` 之外，
依据是有真实文章支撑的显式否决信号。

#### Scenario: 图片来源行不被抢成标题

- **WHEN** 居中 20px 文本「图片来源：Facebook」出现在图片后
- **THEN** 判为 `K="cap"`（图注），不判 `K="h"`

#### Scenario: 参考来源头不被抢成标题

- **WHEN** 居中 20px 文本「参考来源：」
- **THEN** 不判 `K="h"`，且开启参考来源区，使其后 `[1] …` 条目走 `txt`

#### Scenario: 左对齐大字不判标题

- **WHEN** 一个左对齐（非居中）的 22px 非加粗块
- **THEN** 不判 `K="h"`（缺少「居中」这一第一性信号）

#### Scenario: 灰色或小字图注仍是图注

- **WHEN** 图片后一行为 14px 或灰色（如 #888）文本
- **THEN** 判为 `K="cap"`，不因居中而被抢成标题

### Requirement: 分类器判据的修复必须遵循「删巧合依赖、全样例回归」协议

当章节标题/图注识别出现漏判或误判时，修复 MUST 遵循固定协议，MUST NOT 通过「再叠加一条
针对新样例的排除/命中条件」来打补丁。

#### Scenario: 定位到最小真实差异后删除巧合依赖

- **WHEN** 一个真标题被漏判，且与被正确识别的同类兄弟的唯一真实差异是某个非语义属性
  （如少一个 `<b>`、少一个冒号）
- **THEN** 修复方式 MUST 是移除识别规则对该属性的依赖，而非新增一个只覆盖该形状的分支

#### Scenario: 负向测试只引真实文章

- **WHEN** 为标题/图注判据新增或修改测试
- **THEN** 负向（断言「不是标题」）用例 MUST 来自真实文章的观测 HTML，MUST NOT 使用臆造字符串
  断言一个没有真实文章支撑的边界

#### Scenario: 改动后跑通全部历史病样

- **WHEN** 修改任一标题/图注判据
- **THEN** MUST 一次性通过全部历史病样回归（不只验证新触发的那一篇），并跑 `go test ./...` 与 `npm test`
